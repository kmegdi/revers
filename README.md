# Free Fire Info & Likes Telegram Bot

بوت تيليجرام متكامل يقدم ميزتين أساسيتين:
1. **جلب معلومات حسابات Free Fire** باستخدام UID.
2. **إرسال 100 لايك حقيقي** لحسابات Free Fire.

تم تطويره من قبل: **XZANJA & BOMBA**

---

## المميزات

- جلب معلومات دقيقة لحسابات Free Fire عبر UID.
- إرسال 100 لايك حقيقي باستخدام API خاص.
- منع التشغيل في الخاص أو المجموعات غير المصرح بها.
- تحكم كامل للمشرفين لتفعيل البوت في المجموعات.
- تصميم رسائل تفاعلية جذابة باستخدام HTML.
- دعم لأكثر من أمر مفيد.

---

## الأوامر المتوفرة

| الأمر | الوظيفة |
|------|---------|
| `/start` | عرض رسالة ترحيبية وتعليمات الاستخدام |
| `/info [UID]` | جلب معلومات الحساب |
| `/like [UID]` | إرسال 100 لايك للحساب |
| `/check [UID]` | فحص ما إذا كان الحساب مبند |
| `/visit [UID]` | إرسال زائر للحساب |
| `/spam [UID]` | إرسال طلب صداقة |
| `/remaining` | عدد اللايكات المتبقية اليوم |
| `/allowed [group_id]` | السماح للمجموعة باستخدام البوت (للمشرفين فقط) |
| `/list` | عرض قائمة المجموعات المصرح بها |
| `/help` | شرح استخدام البوت |
